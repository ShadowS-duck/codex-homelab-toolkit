# Contributing

Contributions should improve one focused workflow and include concrete trigger
examples, non-goals, validation, and safety behavior.

1. Read `AGENTS.md` and the relevant catalog entry.
2. Keep environment-specific data out of the repository.
3. Scaffold new skills with the official skill creator.
4. Add deterministic scripts only when reliability or repetition justifies them.
5. Run `./scripts/validate.sh`.

Use Conventional Commits. Treat stable skill and plugin interfaces as versioned
public contracts.
