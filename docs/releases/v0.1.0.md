# ShadowS-duck Homelab v0.1.0

First public pre-stable release of the reusable Codex homelab toolkit.

## Included

- a repository-backed personal Codex marketplace;
- plugin `shadowsduck-homelab` version `0.1.0`;
- four tested foundation skills;
- sanitized read-only Linux baseline collection;
- validation, security scan, synthetic scenarios, deterministic ZIP artifact,
  and SHA-256 checksums.

## Boundaries

This release does not contain credentials, host-specific configuration, an MCP
server, or arbitrary remote execution. It does not authorize changes to a live
homelab. The previous private Raspberry control plugin is not included.

The release is pre-stable. Live target compatibility, version-to-version
upgrade, and rollback evidence remain future gates.
