# Legacy Raspberry Control Migration

## Decision

Do not publish or copy the existing `raspberry-control` plugin as-is. Keep it
available temporarily for compatibility, but treat it as deprecated and do not
use its arbitrary execution tool for unattended changes.

## Why replacement is required

- A general-purpose remote shell tool has a much larger authority surface than
  the four foundation skills require.
- The status probe assumes services from an older Raspberry installation.
- Tool output has a size limit but no structured redaction or evidence schema.
- The plugin has no automated tests, compatibility contract, or release gate.
- Its declared skills directory contains no skill implementation.
- Generated bytecode is present in the local plugin directory and must never be
  migrated.

The absence of embedded credentials is a positive property and must be
preserved. Authentication should remain owner-controlled and revocable outside
the published plugin.

## Safe replacement shape

The replacement should be a target adapter consumed by reviewed skills, not a
generic remote shell bridge. Its first release may expose only bounded,
read-only operations:

1. verify target identity;
2. collect the sanitized baseline contract;
3. report tool and command availability;
4. return structured exit status, limitations, and redaction metadata.

Mutating operations must be separate, narrowly named, disabled by default, and
introduced only with target confirmation, preflight evidence, backup checks,
rollback instructions, and tests.

## Retirement gate

Retire the legacy plugin only when all of the following are true:

- the replacement is versioned in this repository;
- synthetic and disposable-host tests pass;
- install, upgrade, reinstall, and rollback behavior are verified;
- the consumer homelab repository selects the target without publishing private
  connection details;
- a read-only Raspberry audit succeeds through the replacement;
- no required workflow depends on arbitrary command execution.

Removal is a separate owner-visible change. Until that gate is met, the legacy
plugin remains installed but unchanged.
