# Changelog

All notable changes follow semantic versioning and are recorded here.

## [0.1.0] - 2026-08-29

### Added

- `shadowsduck` Codex marketplace metadata;
- `shadowsduck-homelab` plugin with four tested foundation skills;
- sanitized Linux baseline collector and anti-leak tests;
- synthetic acceptance scenarios for audit, bootstrap planning, change review,
  and documentation synchronization;
- portable validation, security scanning, deterministic release packaging, and
  GitHub Actions automation;
- personal-tooling inventory and safe migration criteria for the legacy private
  Raspberry control bridge.

### Security

- live targets remain outside the public repository;
- plugin installation does not grant infrastructure mutation authority;
- no MCP server or generic remote execution capability is included.
